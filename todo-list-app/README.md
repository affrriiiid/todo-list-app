# To-Do List Application

A simple console-based To-Do List Manager built using Python.

## Features

- Add tasks
- View tasks
- Remove tasks
- Save tasks permanently using a text file

## Concepts Used

- File Handling
- Lists
- String Manipulation
- Loops
- Conditionals

## How to Run

```bash
python todo.py
```

## Example

Users can add, view, and remove tasks through a command-line menu.
